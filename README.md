# 🎨 그림 마피아 (프로토타입)

한 캔버스에 순서대로 이어 그리고, 숨어있는 마피아를 찾아내는 실시간 멀티플레이어 소셜 추리 게임.

## 서버 계속 켜두기

**`start-all.bat` 을 더블클릭**하세요. 두 개가 같이 뜹니다.

- **서버 창** — 서버가 죽으면 3초 뒤 자동으로 다시 켜집니다. 로그는 `server.log`
- **터널 창** — 외부 접속용 `https://...trycloudflare.com` 주소가 표시됩니다

서버만 켜려면 `start-server.bat` 만 실행하면 됩니다 (`http://localhost:3000`).

> **한계**: 이 PC가 켜져 있어야 하고, 터널 주소는 켤 때마다 새로 발급됩니다.
> 주소를 고정하고 24시간 돌리려면 아래 "상시 호스팅"을 보세요.

### 상시 호스팅 (주소 고정 + PC 꺼도 동작)

`render.yaml` 을 넣어뒀습니다.

1. 이 폴더를 GitHub 저장소로 올립니다 (`node_modules` 는 제외)
2. https://render.com 가입 → **New ▸ Blueprint** → 저장소 선택
3. `https://grim-mafia.onrender.com` 같은 고정 주소가 나옵니다

무료 플랜은 15분간 아무도 안 들어오면 잠들고, 다음 접속 때 30초쯤 깨어나는 시간이 걸립니다.

## 실행 방법

### 0. Node.js 설치 (아직 없다면)

이 PC에는 Node.js가 설치되어 있지 않습니다. https://nodejs.org 에서 **LTS** 버전을 받아 설치한 뒤,
**터미널을 새로 열어서** 아래를 확인하세요.

```bash
node --version
```

### 1. 의존성 설치

```bash
npm install
```

### 2. 서버 실행

```bash
npm start
```

### 3. 테스트

브라우저 탭을 **4개 이상** 열고 각각 http://localhost:3000 접속.

1. 첫 번째 탭: 닉네임 입력 → **새 방 만들기** → 방 코드(5자리) 확인
2. 나머지 탭: 각각 다른 닉네임 입력 → 방 코드 입력 → **입장**
   - 대기실의 "링크 복사" 로 나온 URL(`http://localhost:3000/#ABCDE`)을 붙여넣으면 코드가 자동 입력됩니다.
3. 4명이 모이면 방장 탭에서 **게임 시작!**

> 같은 브라우저의 일반 탭끼리도 각각 별개 소켓이라 정상 동작합니다.
> localStorage에 닉네임이 저장되므로 탭마다 닉네임만 바꿔주세요.

## 게임 흐름

| 페이즈 | 시간 | 내용 |
| --- | --- | --- |
| 대기실 | - | 4~6명 모이면 방장이 시작. **룰 설명 상시 표시** |
| 역할 확인 | 10초 | 시민은 **단어**, 마피아는 **카테고리만** 확인 + **룰 재확인** |
| 그리기 | 턴당 최대 15초 × 2바퀴 | **한 획만!** 마우스를 떼면 즉시 다음 사람 |
| 토론 | 60초 | 완성된 그림 보며 채팅. **전원 동의 시 조기 투표** |
| 투표 | 30초 | 마피아로 의심되는 사람 지목 (전원 투표 시 즉시 종료) |
| 마피아 찬스 | 25초 | **잡힌 마피아가 단어를 맞히면 역전승** (헷갈리는 보기 6개) |
| 결과 | - | 정답 단어 / 마피아 공개, 방장이 "다시하기" |

- 4~5명 방 → 마피아 1명, 6명 방 → 마피아 2명
- 그리기/역할확인 페이즈에는 단어 유출 방지를 위해 채팅이 막힙니다

### 승패 판정

```
투표 결과
├─ 동점 (지목 실패)        → 마피아 승리
├─ 지목된 사람이 시민       → 마피아 승리
└─ 지목된 사람이 마피아
   └─ 마피아 찬스 (보기 6개 중 정답 고르기)
      ├─ 맞힘   → 마피아 역전승
      └─ 틀림/시간초과 → 시민 승리
```

마피아가 2명인 방에서는 그중 **지목당한 한 명**이 맞히기를 시도합니다.

### 누적 점수

여러 라운드를 이어서 하면 점수가 쌓입니다. 대기실·사이드바·결과 화면에서 볼 수 있습니다.

| 상황 | 점수 |
| --- | --- |
| 시민 승리 | 시민 전원 **+1**, 그중 **마피아를 지목한 시민 +1 더** |
| 마피아 승리 (안 들킴 / 동점) | 마피아 **+3** |
| 마피아 역전승 (들켰지만 단어 맞힘) | 마피아 **+2** |

- 마피아를 못 잡으면 시민은 0점이므로, 찍기라도 하는 게 이득입니다
- 점수는 **닉네임 기준으로 보관**되어 대기실에서 새로고침해도 복원됩니다
- 방장은 대기실/결과 화면에서 `점수 초기화` 가능 (라운드 수도 함께 리셋)

### 그리기 룰 (중요)

**한 턴에 한 획입니다.** 마우스를 누르고 → 그리고 → 떼면 그 턴이 바로 끝나고 다음 사람에게 넘어갑니다.
15초는 "그 안에 안 그리면 넘어가는" 상한선일 뿐입니다. 색·굵기는 **그리기 전에** 골라두세요.
4명 기준 한 라운드에 총 8획(각자 2획)으로 그림이 완성됩니다.

## 구조

```
server.js            Express + Socket.io 서버. 모든 게임 상태는 메모리(rooms Map)에 저장
public/index.html    빌드 없이 UMD React + Babel standalone 로딩
public/app.jsx       React 클라이언트 전체 (브라우저에서 Babel이 JSX 변환)
public/styles.css    최소한의 스타일
```

**빌드 단계가 없습니다.** `npm install` 후 `node server.js` 하나면 끝이고,
React/ReactDOM/Babel은 `node_modules`의 UMD 빌드를 서버가 그대로 서빙합니다.
`public/app.jsx`를 수정하고 브라우저를 새로고침하면 바로 반영됩니다.

## 혼자 테스트하기 🤖

사람을 4명 모으지 않아도 **봇과 함께 혼자 다 돌려볼 수 있습니다.**

1. 방을 만듭니다
2. 대기실 아래 `🤖 혼자 테스트하기` 에서 **`인원 채우기`** 를 누릅니다 (부족한 만큼 봇이 채워집니다)
3. `게임 시작!`

봇이 하는 일:

| 페이즈 | 봇 행동 |
| --- | --- |
| 그리기 | 자기 차례에 낙서를 한 획 긋고 넘김 |
| 토론 | "그거 좀 이상했는데" 같은 말을 던지고, 잠시 뒤 조기 투표에 동의 |
| 투표 | 자기 빼고 아무나 랜덤 지목 |
| 마피아 찬스 | 봇이 마피아로 걸리면 아무 단어나 찍음 |

봇도 마피아가 될 수 있고 점수도 쌓입니다. `봇 +1` / `봇 −1` 로 인원을 조절하세요
(봇은 대기실에서만 추가·제거할 수 있습니다).

## 캐릭터

홈 화면에서 **피부색 · 헤어 · 머리색 · 눈 · 입 · 악세사리**를 각각 6~7종에서 고릅니다
(🎲 버튼으로 랜덤). 브라우저에 저장되어 다음에 들어와도 유지됩니다.

- 플레이어 목록에 자기 캐릭터가 프로필로 붙습니다
- **채팅을 치면 그 캐릭터 옆에 말풍선**이 4.5초간 뜹니다
- 채팅 로그에도 작은 캐릭터가 함께 표시됩니다

## 재접속

와이파이가 잠깐 끊기거나 앱을 전환해도 **자동으로 원래 자리로 돌아옵니다.**

- 끊기면 자리를 45초간 비워두고 기다립니다 (`GRACE_MS`)
- 같은 닉네임으로 돌아오면 자리 · 점수 · 캐릭터 · **방장 권한**까지 복구
- 45초가 지나면 그때 자리를 정리합니다
- `나가기` 를 직접 누른 경우에는 기다리지 않고 바로 정리합니다

## 진행 상황 표시

- **차례 알림**: 턴이 바뀌면 화면 중앙에 2초간 크게 표시. `pointer-events: none`이라
  알림이 떠 있는 동안에도 바로 그릴 수 있습니다 (2초를 까먹으면 손해라서)
- **시간 압박**: 남은 시간 5초 이하면 화면 가장자리가 붉게 점멸.
  `prefers-reduced-motion`을 켠 사용자에게는 점멸 대신 고정 표시
- **조기 투표 현황**: 누가 눌렀는지 채팅에 `🗳️ 철수 님이 바로 투표하자고 했습니다. (1/4 찬성)`로 기록

그리는 중에도 채팅할 수 있습니다. 대신 **서버가 정답 단어를 하트로 가립니다.**

| 입력 | 표시 |
| --- | --- |
| `이거 판다 아니야?` | `이거 ❤️❤️ 아니야?` |
| `판 다 맞지` | `❤️❤️ 맞지` |

> **한계**: 한글 정답 문자열 기준이라 `PANDA` 같은 영문 표기나 `귀여운 흑백 곰` 같은
> 우회 설명은 막지 못합니다. 완전 차단은 불가능하므로 이 부분은 매너에 맡깁니다.

## 모바일 지원

- **768px 이하**에서 좌우 2단 레이아웃이 세로 1단으로 바뀝니다 (캔버스 먼저, 그 아래 플레이어/채팅)
- 버튼·입력창 최소 높이 **44px**, 본문 16px (iOS 입력 시 자동 확대 방지)
- 투표 카드와 마피아 맞히기 보기는 좁은 화면에서 1열로 크게 배치
- 캔버스는 `touch-action: none`이라 손가락으로 그릴 때 페이지가 스크롤/줌 되지 않습니다

### 터치 드로잉이 동작하는 방식

캔버스는 **Pointer Events**(`pointerdown/move/up`)를 씁니다. 이건 마우스·터치·펜을 하나로 처리하는
표준 API라, 스마트폰에서 손가락으로 그으면 브라우저가 `pointerType: 'touch'`로 같은 이벤트를 보냅니다.
**따로 `touchstart/touchmove/touchend`를 추가하면 한 번의 터치가 두 번 그려지므로**,
Pointer Events를 지원하지 않는 구형 브라우저(iOS 12 이하)에서만 touch 리스너가 등록되도록
`if (window.PointerEvent) return;`으로 막아두었습니다.

## 디버그 도구

동기화가 어긋나는 것 같을 때 서버와 각 클라이언트의 획 데이터를 직접 비교할 수 있습니다.

- **서버 기준 데이터**: `http://localhost:3000/debug/room/<방코드>`
- **브라우저 콘솔**: `__gm.summary()` (획별 점 개수) / `__gm.strokes()` (전체 좌표)

둘의 획 id·점 개수가 같으면 동기화가 정상입니다.

캔버스는 `requestAnimationFrame`으로 다시 그리되, 백그라운드 탭에서는 rAF가 멈추므로
250ms `setInterval` 폴백과 `visibilitychange` 핸들러를 함께 두었습니다.
그래서 다른 탭에 갔다 돌아와도 캔버스가 항상 최신 상태입니다.

## 설정 바꾸기

`server.js` 상단 `CONFIG` 에서:

```js
MIN_PLAYERS: 4,      // 혼자 테스트하려면 1로
MAX_PLAYERS: 6,
LAPS: 2,             // 몇 바퀴(=1인당 몇 획) 그릴지. 그림이 부실하면 3~4로
TURN_MS: 15_000,     // 턴 상한 (한 획 끝내면 즉시 넘어감)
DISCUSS_MS: 60_000,
VOTE_MS: 30_000,
GUESS_MS: 25_000,    // 마피아 맞히기 시간
GUESS_OPTIONS: 6,    // 맞히기 보기 개수 (줄이면 마피아가 유리)
GUESS_MODE: 'choice' // 'choice' 객관식 / 'text' 주관식 입력
```

### 맞히기 보기 단어

같은 카테고리에서 아무거나 뽑으면 너무 쉬워서, 단어별로 **헷갈리는 보기**를 따로 만들어 뒀습니다
(`server.js`의 `SIMILAR`). 예: `피자` → 와플·팬케이크·부침개·파이·또띠아.

주관식으로 바꾸려면 `GUESS_MODE`를 `'text'`로 두면 됩니다. 띄어쓰기·기호를 무시하고 채점하지만,
동의어(`계란후라이` vs `달걀후라이`)는 오답 처리되므로 난이도가 확 올라갑니다.

한 획 룰 때문에 그림이 너무 단순하다면 `LAPS`를 3~4로 올리는 걸 추천합니다.

단어 목록은 바로 아래 `CATEGORIES` 객체에서 추가/수정하면 됩니다.

## 알려진 제약 (프로토타입)

- 서버 재시작 시 모든 방이 사라집니다 (DB 없음)
- 탭 새로고침 시 같은 닉네임으로 재입장하면 원래 슬롯을 이어받습니다
- 실행 취소(Undo) 없음 — 흰색 브러시가 지우개 역할
- 게임 **중** 새로고침하면 홈 화면으로 나가므로 코드를 다시 입력해야 합니다
  (같은 닉네임이면 원래 자리와 점수를 이어받지만, 그사이 본인 턴은 넘어갑니다)
